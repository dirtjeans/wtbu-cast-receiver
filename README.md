# WTBU Radio Cast receiver

The Google Cast web receiver for the private WTBU Radio app (application ID 8E9BC3C5), served by GitHub Pages at https://dirtjeans.github.io/wtbu-cast-receiver/. The source of truth lives in the app repo under `cast-receiver/`; this repo only hosts it.

D-Tales Radio's receiver is in `dtales/`, served at https://dirtjeans.github.io/wtbu-cast-receiver/dtales/
(the same page with D-Tales Radio's name, logo and colours).
